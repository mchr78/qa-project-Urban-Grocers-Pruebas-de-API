## Proyecto Sprint 8 — Urban Grocers API

-	Este proyecto automatiza pruebas para la API de Urban Grocers, específicamente para la creación de kits. 
-	Se valida el comportamiento del campo “name” en la solicitud POST al endpoint de creación de kits.
-	Las pruebas se realizan usando Pytest y Requests
-	Verificar que la API maneje correctamente el campo `name` al crear un kit de usuario, incluyendo: Validaciones de longitud, tipos de datos válidos, manejo de campos vacíos y soporte de caracteres especiales.
-	Ejecución de pruebas: python -m pytest create_kit_name_kit_test.py.
-	Se utilizan pruebas positivas y negativas.
-	Al ejecutar las pruebas se detectaron pruebas Aprobadas (5) y No aprobadas (4)
